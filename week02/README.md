# KERT 웹 백엔드 스터디 - 2주차


## 실행 방법

먼저 터미널에서 npm install 명령어를 실행하여 프로젝트에 필요한 패키지들을 설치합니다. 패키지 설치가 완료되면 node app.js 명령어를 입력하여 서버를 시작합니다. 서버가 켜진 상태에서 새로운 터미널을 열고 node check.js 명령어를 실행하여 과제 점검 결과를 확인합니다.

## 구현한 라우트

GET / 요청은 /posts 주소로 자동으로 리다이렉트 처리됩니다. GET /posts 요청은 전체 게시글 목록을 조회하며, keyword 쿼리 스트링이 넘어올 경우 제목에 해당 키워드가 포함된 글만 필터링하여 보여줍니다. GET /posts/new 요청은 글 작성을 위한 폼 페이지를 렌더링합니다. POST /posts 요청은 입력받은 폼 데이터로 새 글을 저장한 뒤 작성된 글의 상세 페이지로 리다이렉트합니다. GET /posts/:id 요청은 전달된 ID에 해당하는 게시글의 상세 내용을 렌더링하며 해당 ID의 글이 없으면 404 페이지를 출력합니다. POST /posts/:id/delete 요청은 선택한 게시글을 삭제하고 게시글 목록 페이지로 리다이렉트합니다.

## (도전) 구현한 것

첫 번째로 검색 기능을 구현하여 /posts?keyword=... 형태의 요청에 맞춰 제목에 키워드가 포함된 게시글만 필터링해 목록으로 출력하도록 했습니다. 두 번째로 빈 제목 방지 기능을 구현하여 제목이 없거나 공백으로만 이루어진 경우 저장하지 않고 400 에러를 응답하도록 했습니다. 세 번째로 커스텀 404 페이지를 구현하여 잘못된 주소 접근이나 존재하지 않는 게시글 접근 시 views/404.ejs 템플릿을 404 상태 코드와 함께 렌더링하도록 작성했습니다.
