# KERT 웹 백엔드 스터디 - 1주차
 
1주차 Express 라우트 과제

## 실행 방법

 1. 프로젝트 폴더에서 터미널을 연다.
 2. 다음 명령어로 서버를 실행한다.

 '''bash
 node app.js
 '''

## 구현한 라우트
 
- `/` : 메인 페이지
- `/about` : 소개 페이지
- `/photo` : 사진 페이지
- `/time` : 현재 시각 페이지
- `/posts` : 게시글 목록 페이지

## 연습 문제
 
10 / 10 통과
 
## (도전) /time 이 새로고침할 때마다 바뀌는 이유
 
세로고침할 때마다 브라우저가 서버에 get 요청하고 서버에서는 /time라우트 함수 재실행하게 된다. 이때 new Data()가 실행되어 현재 시각을 새로 가져오기 때문에 화면의 시각이 바뀐다.
